# Zoo Management System (Java)

## Overview
This project is a simple Zoo Management System developed in Java as an academic exercise.  
It demonstrates object-oriented programming (OOP) concepts such as inheritance, classes, and polymorphism.

---

## Project Structure

The project contains the following classes:

- `Animal.java` → Base class for all animals
- `Parrot.java` → Bird type animal
- `Sheep.java` → Herbivore animal
- `Wolf.java` → Carnivore animal
- `Snack.java` → Food or feeding logic
- `Home.java` → Environment or habitat management
- `Zoo.java` → Main system managing animals and interactions

---

## Concepts Used

- Object-Oriented Programming (OOP)
- Inheritance
- Encapsulation
- Polymorphism
- Class relationships
